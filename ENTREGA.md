# Instruções de publicação e entrega — AT5

1. Formar **dupla real**, adicionar o segundo integrante como colaborador do repositório público.
2. A dupla deve reescrever/revisar a base HTML/CSS/Bootstrap de maneira autoral, pois a AT5 proíbe geração desta parte por IA. Registrar progresso verdadeiro com commits semânticos `feat:`, `style:`, `fix:`, `docs:`, `refactor:` dos dois autores; não fabricar histórico de commits.
3. Implementar e auditar em conjunto os recursos avançados; completar **as três fichas** do `AUDITORIA_IA.md` com código original, diagnóstico, refatoração executada e SHA dos commits reais.
4. Personalizar `README.md`: nomes dos integrantes, matriz de colaboração, screenshot real, URL real do deploy e evidências de testes.
5. Enviar todos os arquivos para a raiz de um repositório público no GitHub, com `index.html` na raiz. **Não envie apenas ZIP como trabalho final.**
6. GitHub → repositório → Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)` → Save.
7. Após publicação, testar em `https://USUARIO.github.io/NOME-DO-REPO/` (maiúsculas e hífens importam), Chrome/Firefox/mobile, e conferir erros F12. A URL depende do nome real escolhido para o repositório.
8. Enviar ao professor link do **site online** e link do **repositório**. Opcionalmente informe tema e integrantes. Não declarar etapas não feitas.
